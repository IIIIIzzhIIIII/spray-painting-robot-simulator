使用说明

快速开始

  1. 在画布右上角「场景」切换洁净厂房、钢结构厂房、储罐区、配电房等不同厂房模型。
  2. 在「喷涂工艺」的涂料参数库选择涂层（QZDS 001–024），查看取料参数；可开启「自适应工艺」自动匹配压力、扇幅、膜厚与速度。
  3. 在画布左下方选择作业面「后墙 / 左墙 / 右墙 / 前墙 / 天花板 / 地面」，点击「框选区域」并拖出矩形，再「生成 S 路径」。
  4. 点击「开始喷涂」或「执行喷涂」，机器人底盘会自动行驶至作业面，伸臂后按 S 形轨迹喷涂并统计面积与耗料。
  5. 点击画布右上角「喷嘴特写」或工艺面板中的按钮，可查看雾化粒子与湿膜堆积的自适应动态。
  6. 画布左上方可快速切换末端模组「喷涂 / 批刮 / 打磨」；右上角「跟随」让相机随机器人移动。

示教与回放

  1. 调整到目标位姿后点击「记录点位」，重复生成轨迹。
  2. 输入名称保存到本地轨迹库，刷新页面后仍可加载。
  3. 点击「轨迹回放」将自动插补各点位并联动喷涂。

视图与分享

鼠标左键旋转、右键平移、滚轮缩放；触屏单指旋转、双指缩放。右上角「跟随」锁定机器人，点击「QR」生成当前访问链接二维码，手机横屏可获得完整操作界面。

离线运行：所有依赖已随项目打包，双击 index.html 即可运行，无需网络。浏览器需支持 WebGL2；若使用 GLB 外部模型，请通过「显示设置 → 选择本地 GLB」载入。
